# Signal Feasibility & Threshold Calibration (Real Data)
## Scope
- **Data**: 2 years of REAL history exported from the FBS MT5 terminal (2024-09-23 .. 2026-09-23 UTC).
- **Symbols**: XAUUSD, GBPJPY, EURUSD.
- **Timeframes studied**: M15, M30, H1 (each has a complete validated two-year real series).
- **M5 excluded**: the FBS demo terminal does not retain M5 history beyond ~14 days (2,740-2,870 bars, 2026-09-09 .. 2026-09-23). A 14-day sample cannot support a feasibility conclusion, so M5 is documented as not evaluable with the current feed and left for future work.
- **No lookahead**: every indicator uses only the trailing window ending at (and in a few cases including) the current bar.
- **No production change**: config/strategy_params.py is not touched by this study.
